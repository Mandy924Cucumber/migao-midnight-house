# 夜半回廊 · Midnight House

用 Godot 4.7 制作的第一人称 3D 恐怖解谜短篇。中文界面，三名可靠的同伴，一段可以完整通关的合作逃生故事。

## 开始游戏

- macOS：双击同目录下的 `开始游戏.command`。启动器会寻找 Applications 或 Downloads 中的 Godot。
- 在 Godot 4.7 中导入 `project.godot`，按 **F5** 运行整个项目。
- 无需网络、付费素材、外部插件或其他服务。其他系统也可用 Godot 4.7 打开项目。

第一次打开会导入字体和声音，并编译材质，可能比后续启动慢。

## 操作

| 操作 | 按键 |
| --- | --- |
| 移动、观察 | WASD、鼠标 |
| 快跑 | Shift |
| 对准物品交互 | E |
| 开关手电 | F |
| 笔记、阶段提示 | Tab |
| 暂停、恢复鼠标 | Esc |

设置中可调整鼠标灵敏度、环境亮度和音量。手电没有电量限制。窗口失去焦点会自动暂停。

## 故事与内容

午夜醒来，走出卧室，与起居室里的林岚、周屿、许宁会合。陌生的声响催促你们离开别墅，但庭院出口被倒树堵住，只能进入地下通道。

地下室需要依次修复供电、启动排水、发现值班记录、打开密码柜，最后由三名同伴守住开关，玩家转动钥匙，四个人一起逃到晨光里。三名队友都不会背叛玩家。

此版本采用原创程序化场景和风格化几何角色，包含木地板、墙板、壁炉、书架、窗帘、家具、庭院和地下机械设备。剧情通过中文字幕与原创环境音效呈现，未加入真人配音。恐怖来自灯光、环境声音和故事氛围，没有血腥或必死追逐。

主菜单、暂停、笔记、分步提示、错误密码反馈、通关结尾、重新开始和检查点均已实现。存档在 Godot 的 `user://checkpoint.cfg`，保存解谜进度而不是精确站立坐标；读档会把角色放到安全检查点。

## 工程结构

- `scenes/main.tscn`：主场景；运行时构建关卡。
- `scripts/game.gd`：剧情、交互、谜题、检查点和音频。
- `scripts/architecture.gd`：场景搭建、碰撞、材质和静态网格合并。
- `scripts/player.gd`：第一人称移动、手电、视角。
- `scripts/companion.gd`：三名同伴、路线、行走和机关动作。
- `scripts/interface.gd`：中文界面、设置、笔记和结局。
- `shaders/`：程序化表面与轻微暗角。
- `assets/`：已包含所需声音与开源中文字体子集。
- `tests/playthrough.gd`：49 项完整流程与物理交互回归测试。
- `tests/collisions.gd`：48 项碰撞回归检查，覆盖冲刺、镜头、家具、场景设施、队友绕行及窄门通行。
- `captures/`：Godot 实际渲染截图。

为集成显卡采用 Compatibility 渲染器；静态场景按材质合并网格，保留手电动态阴影。材质与音效均可在本地修改。画面定位是可运行的风格化短篇，不是写实商业大作。

## 测试

```sh
godot --headless --path . --script res://tests/playthrough.gd -- --self-test
godot --headless --fixed-fps 60 --path . --script res://tests/collisions.gd -- --self-test
```

测试使用独立的临时检查点，不覆盖正式存档。验证真实角色碰撞、可达交互、谜题前置条件、队友路径、暂停、存档重载、结局与重新开始。自动化通过不等于保证任何设备上都绝无问题。

## 碰撞修复

玩家与队友相互碰撞，队友会用身体形状探测路线并绕行。家具、树干、路灯、倒树、窗帘、画框、机械罐体、阀门和开关台均配有对应碰撞体；可拾取物品的交互范围与实体碰撞分开。玩家头部碰撞范围也已调整，避免贴近物件时镜头进入模型。修改后需要重新运行游戏，已经打开的试玩进程不会自动更新。
